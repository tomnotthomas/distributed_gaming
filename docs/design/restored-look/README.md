# The player app back in its dark look: before and after

The web app at `/` leaves the light Lanterel look from #107 and returns to the look it had before it: the
game's key art full-bleed under a dark bar, with the grey strip beneath. Captured signed out at `/`; desktop
is the first 1440 × 900 viewport, scaled down, and phone the first 390 × 844 screen. "Before" is `main`
with #107 (the light look, as https://swiff.onrender.com/ shows it now); "after" is this change.
